# Historias de usuario

## RF-01 — Autenticación
Como usuario del sistema, quiero poder registrarme en la página, iniciar y cerrar mi sesión con mis datos de usuario y contraseña, además de poder recuperar mi contraseña en caso de olvidarla, para poder tener acceso a toda mi información y no perder mi registro.

## RF-02 — Perfil
Como Usuario, quiero poder actualizar mis datos (nombre, teléfono y empresa) y que mi correo aparezca como identificador para poder tener mis datos actualizados en caso de que alguno cambie y no tener que preocuparme de crear un nombre de usuario.

## RF-03 — Crear ticket 
Como cliente, quiero registrar una solicitud de soporte indicando título, categoría, descripción y prioridad sugerida, para que el equipo pueda revisarla y darle seguimiento.

## RF-04 — Mis tickets
Como cliente, quiero poder ver todas mis solicitudes en la pagina de Ntek para poder realizar seguimiento y tener registro de los avances.

## RF-05 — Detalle
- Como cliente, quiero consultar el detalle completo de mi solicitud (historial, comentarios y archivos), para conocer el avance de mi caso sin tener que preguntar.
- Como técnico, quiero acceder a la información completa, historial, comentarios y archivos de un ticket, para poder trabajar sobre él y dar una respuesta oportuna. 

## RF-06 — Filtros
Como técnico, quiero poder filtrar los tickets por estado, prioridad, categoría y texto, para poder organizarlos de la manera más óptima posible.

## RF-07 — Gestion  
Como técnico o administrador, quiero modificar el estado, la prioridad y la asignación de un ticket, para organizar el trabajo del equipo de mejor manera.

## RF-08 — Comentarios 
- Como usuario, quiero poder agregar respuestas a las solicitudes, para generar una mejor comunicación con el equipo.
- Como técnico o administrador, quiero poder dejar notas internas visibles solo para el equipo, para coordinarnos sin exponer información al cliente.

## RF-09 — Adjuntos 
Como usuario, quiero poder subir imágenes o archivos PDF asociados a un ticket, para respaldar mi solicitud o mi respuesta con evidencia o documentación.

## RF-10 — Panel 
Como equipo NTEK, quiero ver un resumen con los totales de tickets por estado y prioridad, además de los casos más recientes, para saber en qué debemos centrarnos.

## RF-11 — Usuarios
Como administrador, quiero listar usuarios, cambiar su rol, y activar o desactivar perfiles, para tener control tanto de los clientes como del equipo, desactivando el acceso de quienes ya no deben tenerlo sin perder su historial.

## RF-12 — Auditoria  
Como administrador, quiero poder consultar el historial de acciones relevantes (quién hizo qué y cuándo) sobre los tickets y usuarios, para tener trazabilidad y poder resolver dudas o disputas.
